1. Introduction to ES6+ Variables

Module 1 of 5 • 25 min read

JavaScript is a scripting language that enables you to create dynamically updating content, control multimedia, animate images, and pretty much everything else. ES6 (ECMAScript 2015) introduced major new features to the language.

Let and Const

Prior to ES6, variables were declared using the var keyword. Today, it is highly recommended to use let and const for variable declaration due to their block-scoping rules.

const name = "Alice";
let age = 25;

if (age > 18) {
  let isAdult = true;
  console.log(name + " is an adult.");
}
// console.log(isAdult); // Error! Block-scoped
Pro Tip: Default to Const
Always use const by default. Only change it to let if you know the variable's value needs to be reassigned later (like in a loop).

Template Literals

Template literals provide an easy way to interpolate variables and expressions into strings. You use backticks (` `) instead of quotes.

const greeting = `Hello, my name is ${name} and I am ${age} years old.`;
console.log(greeting);
